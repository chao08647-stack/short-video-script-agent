# 素材检索策略

## 用途与触发

当开始创作、需要产品事实或用户提出新卖点时使用。规划本地检索词，并选择真正相关的资料作为证据。

## 输入

主题、产品名、需要证实的功能或数字、已有搜索记录。

## 产出

检索查询、命中资料 ID 和可用于当前脚本的原文事实。

## 操作约束

1. 从产品名加核心功能开始，使用 search_materials 查询本地资料。
2. 检查命中结果是否属于目标产品和适用版本，不能为了拿到结果换成其他品牌。
3. 保存来源 ID 与支持原文。检索分数只说明相关性，不证明事实已被支持。
4. 返回中有冲突线索时继续查证；空结果时考虑改变查询或请求补充。

## 验证示例

请求介绍小剪字幕功能，可查询“小剪 字幕”，得到 P01/P02 后只采用其原文中的自动生成和手动修改事实。

## 使用证据

运行记录应关联本技能的加载事件、选用理由和实际产生的方向或脚本变化。仅加载本文件不等于完成该能力。

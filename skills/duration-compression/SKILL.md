# 时长压缩

## 用途与触发

当 estimate_duration 返回超时，或用户明确缩短目标时长时使用。根据工具报告选择压缩位置并复检。

## 输入

当前脚本、逐镜头估时、总时长、目标时长、必须保留的事实。

## 产出

压缩后的新版本脚本和具体修改摘要，随后重新估时。

## 操作约束

1. 先查看占时最多或重复的镜头，优先删冗余开场、合并重复说明、压缩旁白。
2. 保留必要事实与用户明确要求的信息；不能删掉风险提示来假装合规。
3. 不要提高固定语速、篡改工具结果或直接把总时长改成目标值。
4. 同内容旁白与字幕已并行计时，不要再次扣除；无法满足时明确返回未完成并说明缺口。

## 验证示例

初稿实测估算为 38 秒，目标 30 秒。缩短开场并合并重复功能说明后再次调用工具；是否通过以新版实际返回为准。

# 可拍摄画面描述

## 用途与触发

当分镜有旁白但画面笼统、不可拍摄，或需要明确录屏与人物动作时使用。负责单镜头画面执行建议。

## 输入

镜头目的、产品资料和功能边界、已有旁白。

## 产出

具体 visual 描述，说明主体、动作和画面变化，不输出图片或视频。

## 操作约束

1. 使用人能执行的拍摄或录屏描述，例如选中一条字幕并修改文字。
2. 资料未给出按钮名称、界面布局或硬件外观时，使用中性描述，不编造精确 UI。
3. 可以创作使用场景，但不能让画面演示资料中没有的真实产品功能。
4. 为需要操作观察的画面保留最低展示时间，避免用过短镜头掩盖内容量。

## 验证示例

“展示产品很好用”应改为“录屏展示生成字幕后的列表，选中一条字幕修改文字”；无资料时不能增加“自动识别说话人”画面。

# 旁白与字幕编写

## 用途与触发

当需要把分镜信息写成自然口语与易读屏幕字幕，或旁白过长、字幕重复堆叠时使用。

## 输入

分镜目的、已支持事实、风格、目标受众和时长。

## 产出

每个镜头的 narration 与 subtitle；字幕可概括旁白但不得新增卖点。

## 操作约束

1. 旁白使用短句并与画面操作同步，避免大量术语和重复铺垫。
2. 字幕提炼当前镜头核心信息，不必逐字复述旁白；两者同时展示时不应把时长相加。
3. 任何功能与数字都必须有资料支持，不能在字幕中偷偷增加旁白未出现的承诺。
4. 写入完整稿件后调用估时与规则检查，根据结果决定是否修订。

## 验证示例

旁白“生成字幕后，你还可以手动修改其中的文字”，字幕可写“支持手动修改字幕”，但不可写“一键修正所有错误”。

# 无结果查询改写

## 用途与触发

当本地检索没有命中或结果明显不相关时使用。基于实际空结果改写查询，保持原产品和用户主题不变。

## 输入

原查询、实际搜索返回、产品与功能线索、已尝试查询。

## 产出

一个有依据的新查询及简短调整理由；仍无依据时转为请求补充。

## 操作约束

1. 先辨认是词语过于口语、堆叠修饰词还是产品不存在。
2. 将口语表达转换为资料可能采用的功能词，例如“片子里的话变成字”改为“字幕”；可拆分长查询。
3. 不要把所有无结果查询都改成固定词，更不能跨产品捡取无关事实。
4. 有限次数尝试后如仍无资料，说明缺口并停止或请求用户提供资料。

## 验证示例

首次检索“片子里的话变成字”为空，改查同一产品的“字幕”后命中；查询不存在的投影仪仍为空时不能转用耳机资料。

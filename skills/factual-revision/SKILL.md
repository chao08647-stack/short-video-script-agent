# 无依据事实修订

## 用途与触发

当事实检查指出 unsupported 或 uncertain，或者引用与断言不匹配时使用。处理事实性错误而非单纯禁词。

## 输入

检查问题、对应脚本文句、已检索资料原文及用户必须保留的信息。

## 产出

删除、限定或补证后的新稿，更新 claims 和来源引用。

## 操作约束

1. 逐项比较断言和原文，判断是功能不存在、数字缺依据、范围扩大还是引用错配。
2. 原文只支持部分内容时，缩减为受到支持的陈述；无关 claim 必须一起删除，不能留下悬空引用。
3. 必要时进行有目的的补查，但不得重复无效查询制造已验证假象。
4. 无法确认且用户坚持该卖点时，解释资料缺口并请求补充；不把人工意见当作客观证据。

## 验证示例

资料只有“自动生成字幕”，稿件写“效率提升80%”。删除效果数字，保留功能介绍，更新引用并重新核验。

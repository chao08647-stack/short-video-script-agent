# 分镜编排

## 用途与触发

当已确定叙事大纲，需要拆分镜头、安排先后顺序和分配信息时使用。负责镜头结构和依赖，不负责添加新事实。

## 输入

叙事大纲、来源事实、用户时长、已有镜头。

## 产出

有稳定 scene_id 的 scenes 列表，每镜头包含一项核心信息和必要来源。

## 操作约束

1. 将叙事节点映射为可独立拍摄或录屏的镜头，通常以少量镜头表达清楚。
2. 安排操作依赖，例如先生成字幕、再修改字幕；不要把操作顺序颠倒。
3. 合并重复信息而非机械增加镜头数，给画面设置合理最低展示时间。
4. 镜头时长最终由估时工具计算，不能靠手写总时长宣布通过。

## 验证示例

把“字幕输入困扰—自动生成—手动修改”编成 S1/S2/S3，生成操作应先于修改操作，P01/P02 分别对应相关镜头。

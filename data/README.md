# 合成资料与规则

全部品牌、产品事实和数字均由项目作者为测试构造，不对应真实商品。

- `demo`：小剪 App 字幕功能、澄音 H1 耳机功能。每条资料包含来源 ID、版本、原文、结构化事实和检索关键词。
- `empty`：空资料库，用于验证无素材时的补查、追问或停止。
- `conflict`：同一耳机续航的两份矛盾资料。日期不同，但没有适用范围与优先级，不能自行采信较新记录。

语速、字幕阅读速度和最低镜头展示时间为可审阅的估时参数，不代表实际配音测量。字幕和旁白同时出现时取所需时间的较大值，不相加。

`examples/inputs` 中的初稿修订样例明确标记为用户提供初稿；这些内容用于制造可复现的问题，不冒充模型真实生成结果。真实模型运行记录与 Mock 记录由评估命令分别生成。

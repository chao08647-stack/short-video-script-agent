# 受众与表达角度规划

## 用途与触发

当资料已知但需要决定向谁讲、解决什么具体困扰、采用哪个表达角度时使用。为方向审核形成可解释的主张。

## 输入

受众描述、主题、已检索到的产品事实、用户表达偏好。

## 产出

一个明确表达角度、受众困扰和采用该角度的简短依据，写入方向方案。

## 操作约束

1. 使用用户给出的受众，不根据年龄、身份等猜测其消费能力或专业水平。
2. 从资料支持的功能出发，将功能映射到可描述的使用情景；不能把情景推测写成产品效果证据。
3. 选择一个适合短时长的核心角度，列出放弃的冗余信息可放在 notes。
4. 方向中标明拟用资料 ID，交由用户确认再写完整脚本。

## 验证示例

同为字幕功能，面向新手可选择“生成后检查与修改”的操作角度，面向团队可强调操作流程，但资料未支持协作功能时不能新增“多人协同”。

## 使用证据

运行记录应关联本技能的加载事件、选用理由和实际产生的方向或脚本变化。仅加载本文件不等于完成该能力。

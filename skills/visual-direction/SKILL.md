# 可拍摄画面描述

## 用途与触发

当分镜有旁白但画面笼统、不可拍摄，或需要明确录屏与人物动作时使用。负责单镜头画面执行建议。

## 输入

镜头目的、产品资料和功能边界、已有旁白。

## 产出

具体 visual 描述，说明主体、动作和画面变化，不输出图片或视频。

## 操作约束

1. 使用人能执行的情景拍摄或抽象动画描述；只有资料明确支持真实界面与操作时才建议对应录屏，功能存在不证明界面结构存在。
2. 资料未给出按钮名称、界面布局、触控位置或硬件外观时，不编造这些细节；改用明确不代表真实 App 布局或交互的抽象示意。
3. 可以创作使用场景，但不能让画面演示资料中没有的真实产品功能；“示意”标签不豁免无依据的功能或效果承诺。
4. 为需要操作观察的画面保留最低展示时间，避免用过短镜头掩盖内容量。

## 验证示例

资料仅支持“自动生成字幕”和“手动修改字幕文字”时，可写：“抽象示意动画：字幕文字浮现，其中一处文字被替换，表现生成与修改的概念；画面为设计示意，不代表真实 App 布局或交互。”不能据此补造真实字幕列表或录屏操作；无资料时不能增加“自动识别说话人”画面。

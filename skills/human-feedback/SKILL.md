# 人工反馈整合

## 用途与触发

当用户在方向、初稿或终稿审核时要求修改，或新意见与原要求产生冲突时使用。将意见落实到可检查的新版本。

## 输入

审核阶段、绑定版本、用户文字意见、原始与当前需求、已有检查结果。

## 产出

修改摘要、新方向或新稿件，以及需要重新审核的阶段。

## 操作约束

1. 先识别用户是在改措辞、镜头还是主题/受众/平台/风格/时长，不静默覆盖原硬性要求。
2. 普通表达意见修改当前稿件；改变核心要求时回到方向审核。
3. 按意见做实际修改，保留不受影响且已成功的资料与内容。
4. 新版必须重新检查并送到正确审核门；不能把“请修改”当“批准”，不能复用旧稿批准。

## 验证示例

终稿意见“把开头改成直接展示操作”，应修改开场并复检后再次送终稿审核；意见“改成面向专业剪辑师的60秒教程”需重新确认方向。

## 使用证据

运行记录应关联本技能的加载事件、选用理由和实际产生的方向或脚本变化。仅加载本文件不等于完成该能力。

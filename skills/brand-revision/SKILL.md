# 品牌规则修订

## 用途与触发

当品牌检查发现禁用表达、绝对化承诺或与品牌语气不符的内容时使用。负责品牌层面修订。

## 输入

规则 ID 或违规描述、脚本中受影响文本、品牌规则和用户风格。

## 产出

修正品牌问题的新版本及对应修改原因。

## 操作约束

1. 定位违规发生在标题、旁白、字幕还是画面，修正所有出现位置。
2. 将“全网第一”“百分百准确”等无法支持的承诺改为资料支持的中性功能介绍。
3. 不能通过同义词替换保留原来的夸大含义，也不能为满足风格牺牲事实。
4. 修改后重新检查整个版本；人工初稿批准不豁免品牌违规。

## 验证示例

初稿标题“全网第一字幕神器”被禁用词规则命中，应改为具体功能标题，并确认旁白和字幕中没有重复承诺。
